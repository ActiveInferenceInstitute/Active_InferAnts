# Freedom of Information Act (FOIA)

FOIA request processing and analysis for government transparency data across 18 federal agencies.

## Structure

| Directory | Description |
|---|---|
| `FOIA_Resources/` | Templates, guides, and reference materials for FOIA requests |
| `FOIA_Responses/` | Collected FOIA responses organized by federal agency (18 agencies) |
| `data/` | Structured datasets including annual compliance reports |

## Covered Agencies

DHS, DOC, DOD, DOE, DOI, DOJ, DOL, DOS, DOT, ED, EPA, HHS, HUD, OIP, SSA, TREASURY, USDA, VA
