# AGENTS.md — FieldSHIFT-2

> Agent guidance for the `1_PREPARE/Methods/Research/FieldSHIFT-2` directory.

## Purpose

Domain-shifting dissertation framework (FieldSHIFT-2) for cross-disciplinary Active Inference analysis. Includes a Python-based dissertation generation pipeline, 24-language translations, and multi-agency grant evaluations.

## Directory Contents

### Pipeline Scripts

- 📄 `config.py` — Configuration and domain definitions
- 📄 `shift_domains.py` — Domain shift definitions and mappings
- 📄 `generate_pro_shift_domains.py` — Pro-level domain shift generation
- 📄 `dissertation_generator.py` — Dissertation text generation
- 📄 `dissertation_outline_generator.py` — Dissertation outline generation
- 📄 `dissertation_explainer.py` — Dissertation explainer module
- 📄 `dissertation_improver.py` — Iterative dissertation improvement
- 📄 `dissertation_translation.py` — Multi-language translation pipeline
- 📄 `dissertation_entity_evaluation.py` — Entity-based evaluation
- 📄 `dissertation_grant_evaluator.py` — Grant proposal evaluation
- 📄 `Meta_Analysis_Shifted_Dissertation.py` — Meta-analysis of shifted dissertations
- 📄 `Meta_Analysis_Shifted_Dissertation_Outline.py` — Meta-analysis of outlines
- 📄 `utils.py` — Shared utilities

### Data & Documentation
