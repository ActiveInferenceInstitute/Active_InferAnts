# Grant Methods

Automated grant proposal generation pipeline using catechism-based structured interviews.

## Pipeline

1. **Catechisms**: Structured question templates tailored to each funding agency
2. **Entities**: Researcher/project profiles providing answers
3. **Grants**: Generated proposals combining catechism structure with entity data

## Structure

| Directory | Description |
|---|---|
| `Catechisms/` | Active catechism templates (structured question-answer protocols) |
| `Entities/` | Entity-specific grant data and research profiles |
| `Grants/` | Generated grant proposals |
| `Research_Methods/` | Grant research methodology documentation |
