# Research Workflow

Using FieldSHIFT-2 and grant generation tools for Active Inference research.

## FieldSHIFT-2 Pipeline

Domain-shifting dissertation framework at `1_PREPARE/Methods/Research/FieldSHIFT-2/`:

| Stage | Script | Description |
|-------|--------|-------------|
| 1 | `config.py` | Domain definitions and parameters |
| 2 | `shift_domains.py` | Domain shift mappings |
| 3 | `dissertation_generator.py` | Text generation |
| 4 | `dissertation_outline_generator.py` | Outline generation |
| 5 | `dissertation_explainer.py` | Explanation module |
| 6 | `dissertation_improver.py` | Iterative improvement |
| 7 | `dissertation_translation.py` | 24-language translation |
| 8 | `dissertation_entity_evaluation.py` | Entity evaluation |
| 9 | `dissertation_grant_evaluator.py` | Grant evaluation |

## Grant Generation

Automated grant proposal generation at `1_PREPARE/Methods/Grant_Methods_1/`:

1. **Catechisms** — Structured question-answer templates per funding agency
2. **Entities** — Researcher profiles providing answers
3. **Grants** — Generated proposals combining catechism + entity
