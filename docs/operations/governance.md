## 6-Phase Pipeline Governance

Each phase directory has an `AGENTS.md` defining:
- Purpose and scope
- Module-level descriptions
- Cross-phase dependencies
- Quality checklist

## Documentation Standards

Every directory maintains a documentation triad:

| File | Audience | Content |
|------|----------|---------|
| `AGENTS.md` | AI coding assistants | Directory path, purpose, contents, instructions |
| `README.md` | Human developers | Overview, module tables, usage examples |
| `SPEC.md` | Technical reviewers | Interfaces, dependencies, constraints |

## Quality Assurance

- 413+ directories documented with accurate AGENTS.md
- All module descriptions source-verified against Python code
- Cross-references and parent links validated
- Listing accuracy audited against actual directory contents
