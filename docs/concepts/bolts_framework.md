# BOLTS Framework

Business, Operations, Legal, Technical, Social analysis through Active Inference.

## Five Dimensions

| Dimension | Focus | Active Inference Mapping |
|-----------|-------|--------------------------|
| **B**usiness | Market dynamics, economics | Expected free energy over economic outcomes |
| **O**perations | Process optimization | State transitions as workflow steps |
| **L**egal | Regulatory compliance | Constraints on policy space |
| **T**echnical | System architecture | Generative model structure |
| **S**ocial | Stakeholder engagement | Multi-agent inference with shared beliefs |

## Cross-Dimensional Analysis

BOLTS enables multi-dimensional analysis where changes in one dimension propagate through Active Inference dynamics to affect others. For example:
- A **Legal** constraint restricts available **Technical** actions
- A **Social** signal updates **Business** beliefs
- An **Operational** observation informs **Technical** predictions

## Location

`0_CONTEXT/Systems/BOLTS/` — Subdirectories for each dimension with analysis scripts.
