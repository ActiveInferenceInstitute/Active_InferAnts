# Glossary

Active Inference and Active InferAnts terminology.

| Term | Definition |
|------|-----------|
| **Active Inference** | A theory unifying perception, action, and learning under the Free Energy Principle |
| **Free Energy Principle** | The principle that biological systems minimize variational free energy |
| **Generative Model** | Internal model an agent uses to predict observations (A/B/C/D matrices) |
| **A Matrix (Likelihood)** | Maps hidden states to observations — P(o\|s) |
| **B Matrix (Transition)** | State transition probabilities — P(s'\|s,a) |
| **C Vector (Preferences)** | Log-preferences over observations driving goal-directed behavior |
| **D Vector (Prior)** | Prior beliefs over initial hidden states |
| **Expected Free Energy** | Quantity agents minimize to select actions (balances exploration and exploitation) |
| **Belief Updating** | Bayesian inference to update beliefs given new observations |
| **PyMDP** | Python package for discrete-state Active Inference |
| **Precision** | Inverse variance; higher precision = more confidence in predictions |
| **BOLTS** | Business, Operations, Legal, Technical, Social framework |
| **P3IF** | Privacy, Policy, and Procedure Integration Framework |
| **FieldSHIFT** | Domain-shifting framework for cross-disciplinary analysis |
| **Catechism** | Structured question-answer template for grant proposals |
| **Fonds** | Archival term for a body of records from a single source |
| **InferAnt** | An Active Inference agent in the framework |
| **ActiveNestmate** | Ant colony nestmate agent class |
| **ActiveColony** | Colony-level agent aggregation class |
| **Thing** | Base Active Inference entity class using PyMDP |
| **Cognitive Sovereignty** | Self-determination in cognitive/belief processes |
