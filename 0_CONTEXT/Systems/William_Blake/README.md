# William Blake Analysis

Literary and philosophical analysis of William Blake's works through Active Inference epistemology.

## Modules

| Module | Description |
|---|---|
| `Blake_Analysis.py` | Main analysis pipeline for Blake's works |
| `Blake_Entity_Extraction_Simple.py` | Simple regex-based entity extraction |
| `Blake_Entity_Extraction_Spacy.py` | SpaCy NLP-based entity extraction |
| `Blake_Mentions.py` | Tracking mentions and references across texts |
| `Blake_Zed.py` | Zed-model integration for epistemological mapping |

## Data

- `Blake_Entity.json` — Extracted entity data
- `William_Blake_Resources/` — Source texts and reference materials
- `Analysis/` — Analysis outputs
- `Outputs/` — Generated visualizations and reports
