# Active Data Sampling

Active data sampling strategies using Active Inference for optimal experimental design and data collection.

## Modules

| Module | Description |
|---|---|
| `Methods_ActiveDataSampling.py` | Core sampling methods implementing Active Inference exploration-exploitation |
| `Run_ActiveDataSampling.py` | Execution script orchestrating sampling experiments |
| `Analysis_ActiveDataSampling.py` | Post-hoc analysis of sampling efficiency and coverage |
| `Visualization_ActiveDataSampling.py` | Visualization of sampling distributions and free energy landscapes |

## Usage

```bash
python3 Run_ActiveDataSampling.py
python3 Analysis_ActiveDataSampling.py
python3 Visualization_ActiveDataSampling.py
```
