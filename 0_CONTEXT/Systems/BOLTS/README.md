# BOLTS Framework

Business, Operations, Legal, Technical, Social (BOLTS) framework for multi-dimensional organizational analysis through Active Inference.

## Dimensions

| Dimension | Directory | Description |
|---|---|---|
| **B**usiness | `Business/` | Business strategy, economics, market dynamics |
| **O**perations | `Operations/` | Process optimization, workflow management |
| **L**egal | `Legal/` | Regulatory compliance, legal frameworks |
| **T**echnical | `Technical/` | System architecture, technology stack |
| **S**ocial | `Social/` | Stakeholder engagement, social impact |
