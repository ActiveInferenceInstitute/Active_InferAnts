# Active Inference Core

Core Active Inference system implementations, PyMDP utilities, and variational methods.

## Modules

| Module | Description |
|---|---|
| `VCG.py` | Variational Conjugate Gradient — optimization for free energy minimization |
| `pymdp_all_utils.py` | Comprehensive utility functions for PyMDP model construction |
| `pymdp_flatten.py` | Flattening utilities for hierarchical PyMDP models |
| `pymdp_pull.py` | Extraction utilities for pulling PyMDP model components |
| `PyMDP_methods.md` | Reference documentation for PyMDP methods |
