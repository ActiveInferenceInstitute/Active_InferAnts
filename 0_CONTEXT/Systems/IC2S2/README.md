# IC2S2 — Computational Social Science

Active Inference analysis for the International Conference on Computational Social Science.

## Modules

| Module | Description |
|---|---|
| `main.py` | Main entry point for IC2S2 analysis |
| `utils_active_inference.py` | Active Inference core functions |
| `utils_agents.py` | Social agent definitions and behaviors |
| `utils_analysis.py` | Statistical analysis of social dynamics |
| `utils_data.py` | Data loading and preprocessing |
| `utils_math.py` | Mathematical utility functions |
| `setup.py` | Package setup and dependencies |

## Usage

```bash
python3 main.py
```
