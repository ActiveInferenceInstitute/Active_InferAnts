# Active Inference - Groovy Implementation

## Overview

Active Inference implementation using Groovy, leveraging its GDK enhancements, closures, and JVM ecosystem.

## Features

- Bayesian belief updating
- Free energy calculation
- Softmax policy selection
- GDK collection operations

## Requirements

- Groovy 3.0+ (or JDK with Groovy standalone)

## Usage

```bash
./run.sh
```
