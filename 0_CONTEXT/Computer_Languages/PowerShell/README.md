# Active Inference - PowerShell Implementation

## Overview

Active Inference implementation using PowerShell 5+ classes with .NET integration for belief updating and free energy minimization.

## Features

- Bayesian belief updating
- KL divergence free energy
- Softmax policy selection
- .NET Math integration
- PowerShell class system

## Requirements

- PowerShell 5.1+ or PowerShell Core (pwsh)

## Usage

```bash
./run.sh
```
