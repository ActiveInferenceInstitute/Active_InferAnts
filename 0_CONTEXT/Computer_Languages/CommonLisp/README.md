# Active Inference - Common Lisp Implementation

## Overview

Active Inference implementation in Common Lisp, using structs, closures, and symbolic computation for belief updating and free energy minimization.

## Features

- Bayesian belief updating
- KL divergence free energy
- Softmax policy selection
- CLOS-style structs

## Requirements

- SBCL, CLISP, or ECL

## Usage

```bash
./run.sh
```
