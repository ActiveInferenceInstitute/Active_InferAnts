# Active Inference - D Implementation

## Overview

Active Inference implementation using the D programming language, leveraging D's metaprogramming and compile-time features for efficient belief updating and free energy minimization.

## Features

- Belief updating via Bayesian inference
- Variational free energy calculation (KL divergence)
- Softmax policy selection over expected free energy
- Compile-time array operations

## Requirements

- D compiler (DMD, LDC2, or GDC)
- Standard library only

## Usage

```bash
./run.sh
```
