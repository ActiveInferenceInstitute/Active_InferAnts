# Active Inference - Dart Implementation

## Overview

Active Inference implementation using Dart with null safety, demonstrating belief updating and free energy minimization.

## Features

- Bayesian belief updating
- KL divergence free energy calculation
- Softmax policy selection
- Null-safe type system

## Requirements

- Dart SDK 2.12+

## Usage

```bash
./run.sh
```
