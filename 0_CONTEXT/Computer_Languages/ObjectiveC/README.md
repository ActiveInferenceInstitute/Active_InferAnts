# Active Inference - Objective-C Implementation

## Overview

Active Inference implementation using Objective-C with Foundation framework, leveraging NSMutableArray and Objective-C's object system.

## Features

- Bayesian belief updating
- KL divergence free energy
- Softmax policy selection
- Foundation framework integration

## Requirements

- Xcode Command Line Tools (clang)
- macOS/GNUstep

## Usage

```bash
./run.sh
```
