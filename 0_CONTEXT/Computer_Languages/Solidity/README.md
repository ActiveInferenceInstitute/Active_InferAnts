# Active Inference - Solidity Implementation

## Overview

Active Inference smart contract using Solidity's fixed-point arithmetic (WAD 1e18 precision) for on-chain belief updating and free energy minimization.

## Features

- Fixed-point Bayesian belief updating
- On-chain free energy computation
- EFE-based action selection
- Event logging for off-chain monitoring

## Requirements

- Solidity compiler (solc 0.8+)
- EVM-compatible network (Hardhat, Foundry, or Ethereum)

## Usage

```bash
./run.sh  # Compiles the contract
```

Deploy to a local testnet for interactive simulation.
