# Active Inference - Tcl Implementation

## Overview

Active Inference implementation in Tcl, using dicts, lists, and dynamic typing for belief updating and free energy minimization.

## Features

- Bayesian belief updating
- KL divergence free energy
- Softmax policy selection
- Dict-based agent state

## Requirements

- Tcl 8.5+

## Usage

```bash
./run.sh
```
