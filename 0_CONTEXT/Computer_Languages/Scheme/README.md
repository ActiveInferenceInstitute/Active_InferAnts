# Active Inference - Scheme Implementation

## Overview

Active Inference implementation in Scheme (R7RS), using the functional paradigm with vectors and closures.

## Features

- Bayesian belief updating
- KL divergence free energy
- Softmax policy selection
- Pure functional style

## Requirements

- Chibi-Scheme, Guile, Chicken, or Gauche

## Usage

```bash
./run.sh
```
