# Active Inference - COBOL Implementation

## Overview

Active Inference implementation in COBOL, using the structured Data Division and Procedure Division for belief updating and free energy minimization.

## Features

- Fixed-point belief updating
- Free energy calculation with FUNCTION LOG
- Structured paragraph organization
- Legacy enterprise paradigm

## Requirements

- GnuCOBOL (cobc) 3.0+

## Usage

```bash
./run.sh
```
